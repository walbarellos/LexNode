## 2024-05-24 - HTML Parser Optimization
**Learning:** The application uses BeautifulSoup with the default 'html.parser' in several places. Since the application performs heavy web scraping of large judicial HTML pages, switching to 'lxml' provides a significant performance boost (up to 35-50% faster parsing times) without losing functionality. Also found an unused BeautifulSoup parsing in the fallback regex extraction.
**Action:** Replace 'html.parser' with 'lxml' where BeautifulSoup is used. Add 'lxml' to requirements.txt. Remove the unnecessary BeautifulSoup instantiation in `extrair_resumos_pesquisa_2grau` since it extracts via regex anyway.
## 2024-05-24 - TRF1 Crawler ViewState Optimization
**Learning:** The JSF-based TRF1 crawler was doing a redundant GET request for `javax.faces.ViewState` on *every* search, even when doing concurrent queries or repeated searches. The `CrawlerTRF1` instance is correctly persisted in thread-local storage (`threading.local()` in `app.py`), meaning instances are reused across requests served by the same thread. Caching the ViewState avoids this redundant GET.
**Action:** Always cache JSF ViewStates and Session IDs in stateful crawlers. When caching JSF state, you must implement a retry mechanism that catches HTTP errors (like 500s or 403s caused by `ViewExpiredException`), clears the state cache, re-fetches it, and retries the request to ensure robustness.
