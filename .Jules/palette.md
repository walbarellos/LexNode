## 2024-05-24 - Inheriting Text Color for Loading Spinners
**Learning:** Loading spinners often need to match the text color of the button or element they are placed in, especially when buttons have different states (hover, disabled, primary vs secondary) with different text colors. Creating custom CSS classes for each state combination is tedious and can lead to styling inconsistencies.
**Action:** Use inline styles leveraging `currentColor` (e.g., `style="border-color: currentColor; border-right-color: transparent;"`) on standard spinner elements (like `.loading-mark`). This allows the spinner to automatically and seamlessly inherit the text color of its parent container across all states without requiring any custom CSS overrides.
